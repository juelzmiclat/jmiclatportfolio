# Juelz Miclat Portfolio

A responsive static portfolio for GitHub Pages featuring:

- Internship project gallery
- Two Python word-cloud exercises
- Lung cancer regional data visualization
- ArcGIS Online embedded map
- Tableau placeholder
- Large ArcGIS StoryMaps final-project placeholder
- Separate resume page with PDF preview and download

## Publish with GitHub Pages

1. Create a new GitHub repository, such as `juelz-portfolio`.
2. Upload everything inside this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide the public website URL after deployment.

## Add the Tableau project later

In `index.html`, find the card labeled **Interactive Tableau Exercise**. Replace its placeholder preview with the embed code supplied by Tableau Public. A modal can also be added following the same structure used for the ArcGIS map.

## Add the StoryMaps final project later

In `index.html`, find the section with `id="final-project"`. Replace the `.story-placeholder` block with your StoryMaps iframe or embed code, then update the project title and description.

## Privacy note

The included resume PDF contains personal contact and address information. Since a GitHub Pages site is public, consider replacing it with a redacted public version before publishing.
